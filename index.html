Up and running in 3 steps

Install in under two minutes

No admin rights needed. The .NET runtime is bundled — there’s nothing else to install.

1

Download & run

Click Download, then double-click AI-Repairing-Assistant-Setup-10.1.7.exe. On first launch Windows SmartScreen may warn (the app isn’t code-signed yet) — choose More info → Run anyway.

2

Install

Hit Next → Install. Shortcuts land in your Start Menu and on the Desktop. It’s a per-user install, so no administrator password is required.

3

Add your free Gemini key

Open Settings (gear) → AI Engine, paste a free key from aistudio.google.com/apikey, click Test Key → Save. Chat, photo, voice and schematics all come alive.

SmartScreen note: the warning appears only because the installer isn’t signed with a paid certificate — not because anything’s wrong. The download below has a published SHA-256 you can verify.

Questions

Frequently asked

Is it really free?

Yes. The app is free and full-featured. You only need a Google Gemini API key, which Google provides free at aistudio.google.com/apikey.

Why does Windows show a SmartScreen warning?

Because the installer isn’t signed with a paid code-signing certificate. It’s safe to proceed — click More info → Run anyway. You can also verify the SHA-256 hash published on this page against your downloaded file.

Where is my API key stored?

Encrypted on your PC using Windows DPAPI, in %AppData%\PhoneRepairAssistant\config.json — never in plaintext and never sent anywhere except Google’s API. You can also lock the whole app behind a PIN or password.

Which languages does it understand?

Hindi, Hinglish and English — type or speak in any of them. The model is tuned for board-level repair vocabulary.

Does it work offline?

The AI features need internet because the model runs in the cloud. Local tools — opening schematics, boardviews, OCR and your jumper library — work without a connection.

How do I uninstall it?

Open Settings → Apps → Installed apps (or Add/Remove Programs), find AI Repairing Assistant and click Uninstall.
